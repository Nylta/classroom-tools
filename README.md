# 우리반 수업 도구함

교실에서 바로 쓰는 수업 도구 모음입니다. 한 번 입력한 학생 명단을 모든 도구에서 함께 씁니다.

- **발표자 뽑기**: 무작위로 한 명 뽑기 (뽑힌 학생 제외 가능)
- **모둠 편성**: 모둠 수를 정하면 고르게 섞어서 나누기
- **활동 타이머**: 큰 숫자 표시, 종료 알림음
- **칭찬 점수**: 학생별 +/− 점수
- **학생 명단**: 한 줄에 한 명씩 입력

명단과 점수는 사용하는 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.

## 배포 (GitHub Pages)

저장소 **Settings → Pages** 에서 Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)` 로 지정하면
`https://<사용자이름>.github.io/<저장소이름>/` 주소로 열립니다.
